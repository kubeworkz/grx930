# model must reproduce every number below exactly.

# Operands come from this file's own generator: the model's
# xorshift32 seeded with op_seed ^ 0x2545f491 for A and
# op_seed ^ 0x2545f491 ^ 0x9e3779b9 for B, each value taken as
# (s % 15) - 7.  So a reader needs no operand data.
#
